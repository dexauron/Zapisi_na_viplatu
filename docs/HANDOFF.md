## Документы 1С (2026-10-31)
- ☰ → «Загрузить из 1С»: можно несколько файлов сразу — «Контрагенты», «Приходная накладная», «Расходный кассовый ордер»,
  «Возврат поставщику» (списки документов, «Ещё → Вывести список») и отчёт «Взаиморасчёты с контрагентами». Разбор — `assets/import1c.js`.
- Таблица `docs`: ключ «вид + номер + год». Повтор той же выгрузки: 0 новых, 0 изменённых (проверено на 38 472 документах).
  Пропавшие из 1С за период файла помечаются `deleted` (с защитой от неполного файла).
- Цепочка: `import_docs` пачками по 2000 → `finish_import` (удалённые, основания оплат) → `reconcile` по 100 поставщиков
  (остатки по накладным, связь записей и заказов с накладными, «Оплачено» по 1С). Ручные отметки не отменяются.
- `finish_import` начинается с `analyze`: без свежей статистики после крупной загрузки он не укладывался в 8 с (лимит роли authenticated).
- Кабинет ТП: вкладка «Накладные» (приходы, оплаты, возвраты, долг магазина).
- Номера: везде входящий номер поставщика (`A.docNo`), у ручных накладных — «б/н»; номер 1С — только в подробностях документа.
- «Сегодня» → «Не оплачено в 1С» (`open_invoices`): накладные без расходника, фильтр «без записи», вид по поставщикам / по накладным.
- «Выплаты» → поиск по № накладной: ниже записей — «Накладные в 1С» (`find_invoices`: входящий № с начала, № 1С — только полностью) с кнопками «Записать» и «Оплачено» (создаёт оплаченную запись, есть «Вернуть»).

## Жесты (common.js)
- Свайп строки влево: заказ — «Пришёл» / «Отменить», выплата — «Выплачено» / «К выплате»; полный свайп = первое действие.
- Лист тянется вниз и закрывается; «потянуть вниз — обновить»; календарь листается свайпом.
- Выкладка добавляет `?v=<коммит>` к CSS/JS — браузер телефона не держит старые файлы.

## Без сети и отмена (app.js: write / flush / changeStatus / deleteWithUndo)
- Все изменения заказов и выплат идут через `write()`: без сети — в очередь `localStorage['sverka-queue']`, строка помечается «не отправлено», отправка при появлении сети.
- Данные кэшируются (`sverka-cache`); `sw.js` хранит оболочку — приложение открывается без интернета (нужен хотя бы один вход с сетью).
- Смена статуса и удаление — с кнопкой «Вернуть» 5 секунд; удаление выполняется через 5 секунд (или сразу при закрытии вкладки).
- Новый представитель/магазин — только с сетью.

# Правила для ИИ-исполнителя (Claude, ChatGPT / Codex и другие)

1. В начале работы прочитай `docs/HANDOFF.md`; в конце обнови его: что сделано, что нет, следующий шаг.
2. Архитектурные решения записывай в `docs/DECISIONS.md`.
3. Репозиторий публичный: никаких паролей, секретных ключей, токенов представителей и настоящих персональных данных.
   Адрес проекта и публичный ключ Supabase — только в переменных GitHub (`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`);
   локально — `assets/config.js` (в git не попадает, шаблон `assets/config.example.js`).
4. Новая таблица = миграция + RLS + проверки в `supabase/tests/*_test.sql` в одном коммите.
   Схему меняют только новые файлы `supabase/migrations/<14 цифр>_<имя>.sql`, никогда руками через админку.
5. Деньги — `numeric(12,2)` в базе, суммирование в интерфейсе — в копейках (`App.sum`).
6. Интерфейс — без сборки: HTML + `assets/*.js` + `assets/styles.css` (стиль iOS, цвета только из переменных `:root`).
   Общие помощники — `assets/common.js`; сотрудники и админ — `assets/app.js`; кабинет ТП — `assets/rep.js`.
7. Перед коммитом: `node --check assets/*.js`; база — `supabase start …` и `supabase/tests/run.sh`;
   функции — `deno check` и `deno lint` (команды — `docs/DEPLOY.md`). Тест прав можно прогнать и на облачной
   базе: он заканчивается исключением с отчётом, все изменения откатываются.
8. Владелец — не программист: объясняй простым языком, ручные шаги — по пунктам со ссылками.
9. Язык интерфейса и комментариев — русский, имена в коде — английские.

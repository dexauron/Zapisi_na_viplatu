## Выплаты и поиск (2026-10-30)
- Статусы выплаты: «Запись» (`to_pay`) и «Оплачено» (`paid`). `accrued` в enum остался, триггер `payouts_touch` переводит его в `to_pay`.
- `payouts.invoice_no` — № накладной (видно в кабинете ТП и по общей ссылке, ищется).
- Кружок слева в строке выплаты (как в «Напоминаниях»): тап — оплачено / снять оплату, с «Вернуть».
- Поиск `A.rank` / `A.matches` (common.js): части слов в любом порядке, латиница = кириллица (`canon`), другая раскладка, опечатка в 1 букву, цифры телефона. Выбор представителя в формах — строка поиска с подсказками и «Недавние».

## Жесты (common.js)
- Свайп строки влево: заказ — «Пришёл» / «Отменить», выплата — «Выплачено» / «К выплате»; полный свайп = первое действие.
- Лист тянется вниз и закрывается; «потянуть вниз — обновить»; календарь листается свайпом.
- Выкладка добавляет `?v=<коммит>` к CSS/JS — браузер телефона не держит старые файлы.

## Без сети и отмена (app.js: write / flush / changeStatus / deleteWithUndo)
- Все изменения заказов и выплат идут через `write()`: без сети — в очередь `localStorage['sverka-queue']`, строка помечается «не отправлено», отправка при появлении сети.
- Данные кэшируются (`sverka-cache`); `sw.js` хранит оболочку — приложение открывается без интернета (нужен хотя бы один вход с сетью).
- Смена статуса и удаление — с кнопкой «Вернуть» 5 секунд; удаление выполняется через 5 секунд (или сразу при закрытии вкладки).
- Новый представитель/магазин — только с сетью.

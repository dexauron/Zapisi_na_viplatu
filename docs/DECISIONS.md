# Решения

| Дата | Решение | Почему |
|---|---|---|
| 2026-10-30 | Без интеграции с 1С | Решение владельца |
| 2026-10-30 | Supabase (Postgres + Auth) + статичный сайт на GitHub Pages | Бесплатно; нужен общий доступ сотрудников и ТП с разных устройств |
| 2026-10-30 | Интерфейс без сборки (HTML/JS, supabase-js в `vendor/`) | Решение не сложнее задачи; нет зависимостей от npm при выкладке |
| 2026-10-30 | ТП входит по персональной ссылке `index.html#<токен>` | Без паролей для ТП; токен 144 бита, во фрагменте URL (не в логах и Referer); замена ссылки отзывает старую |
| 2026-10-30 | Токены ТП — отдельная таблица `rep_access`, только админ | Сотрудник не должен видеть выплаты через чужую ссылку |
| 2026-10-30 | Роли `admin` / `employee` в `staff`; учётки — Edge Function `staff-admin` | Ключ сервиса не попадает в браузер; сотрудник входит по логину без email |
| 2026-10-30 | Сотрудник: заказы (создать/изменить/отметить), справочники (добавить). Удаление и выплаты — только админ | Минимум прав для работы магазина |
| 2026-10-30 | «Просрочен» вычисляется, не хранится | Нет рассинхронизации статуса с датой |
| 2026-10-30 | Адрес и ключ проекта — переменные GitHub, не код | Как в CRM-Auron: смена проекта без правки кода |
| 2026-10-30 | ~~Проект Supabase в `us-east-1`~~ | Заменено ниже |
| 2026-10-30 | Переезд в `eu-central-1` (Франкфурт), проект `umwystttvkrgentkddik` | Ближе к Грозному: меньше задержка каждого запроса. Перенос сервер-сервер, пароли и ссылки ТП сохранены. Настоящие персональные данные (152-ФЗ) хранить нельзя |
| 2026-10-30 | «Ещё» → «Открыть» помечает ссылку `?from=app`, и на странице появляется «Назад» | Приложение на телефоне идёт без адресной строки: открыв общую ссылку, владелец оставался без выхода. По ссылке из WhatsApp метки нет — представителю возвращаться некуда |
| 2026-10-30 | «Ещё» убрано из нижних вкладок в кнопку с тремя чёрточками справа вверху | Пожелание владельца; внизу остаётся только ежедневная работа, настройки не занимают место |
| 2026-10-31 | Акт сверки — PDF в браузере (jsPDF 4.2.1, MIT; шрифт PT Sans, OFL) | Настоящий PDF на iPhone, Android и ПК без сервера; «Поделиться» отправляет файл в WhatsApp. Грузится только при первом акте |
| 2026-10-31 | «Получил» ставит только представитель по своей ссылке | Подтверждение от второй стороны; сотрудник поставить не может (триггер) |

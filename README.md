# Заказы и выплаты

Веб-приложение (PWA, стиль iOS) для магазина: сотрудники записывают заказы у торговых представителей, админ ведёт выплаты, представитель по персональной ссылке видит свои заказы и выплаты.

| Кто | Где | Что может |
|---|---|---|
| Админ | `app.html`, email или логин + пароль | всё: заказы, выплаты, представители и их ссылки, магазины, сотрудники |
| Сотрудник магазина | `app.html`, логин + пароль (выдаёт админ) | записать заказ, отметить «Пришёл», отменить, добавить представителя или магазин. Выплаты и ссылки ТП не видит |
| Торговый представитель | `index.html#<токен>` | только просмотр своих заказов и выплат, поиск, итоги |

## Экраны
- **Заказы:** «Ожидаются» с группами Просрочено / Сегодня / Завтра / 7 дней / Позже, «Пришли», «Все». Поиск по представителю, компании, магазину, №, сумме, автору.
- **Новый заказ** (лист снизу): представитель (или «＋ Новый»), магазин (запоминается), сумма, №, дата заказа, дата прихода с быстрыми кнопками Завтра / +2 / +3 / Неделя.
- **Карточка заказа:** «Пришёл», «Изменить», «Отменить»; кто записал и кто изменил.
- **Выплаты** (админ): Начислено → К выплате → Выплачено.
- **Справочник:** представители (сводка, звонок, ссылка, WhatsApp, новая ссылка, отключение) и магазины.
- **Ещё:** профиль, сотрудники (админ), выход.

## Архитектура
- Фронтенд: статичный HTML/CSS/JS без сборки, `supabase-js` 2.118 в `vendor/`. Хостинг — GitHub Pages.
- База: Supabase PostgreSQL. Схема — `supabase/migrations/`.
  - `staff` (роли), `reps`, `rep_access` (токены), `stores`, `orders`, `payouts`, `admins` (email владельца для первого входа).
- Права — RLS:
  - сотрудник: чтение справочников и заказов, создание и изменение заказов;
  - удаление и изменение справочников — только админ;
  - `payouts` и `rep_access` — только админ.
- Учётки сотрудников: Edge Function `staff-admin` (`supabase/functions/staff-admin`). Проверяет, что вызывает админ; ключ сервиса только на сервере. Логин `ivan` = email `ivan@staff.zapisi.app` (письма не отправляются).
- Кабинет ТП: RPC `get_rep_data(token)` от роли `anon`. Токен — 144 бита, передаётся в `#фрагменте` URL.
- Деньги: `numeric(12,2)`, суммирование в копейках.
- Даты/статусы: `delivered_at` и `paid_at` ставят триггеры. «Просрочен» вычисляется: дата прихода прошла, статус «Ожидается».

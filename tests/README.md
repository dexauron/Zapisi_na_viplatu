# Проверки «Сверки»

Зависимость JSDOM используется только тестами. Сайт по-прежнему состоит из статичных файлов без сборки.

Установка проверочного окружения: `npm ci --prefix tests --ignore-scripts`.

Запуск: `npm test --prefix tests`.

Прогон включает разбор 1С, суммы, даты, миграцию офлайн-очереди и настоящие страницы приложения с вымышленными ответами API. Рабочий Supabase не вызывается. В тестах экранов проверяется DOM и взаимодействие с элементами; CSS и реальные мобильные браузеры этим прогоном не проверяются.

Проверки базы запускает существующий `supabase/tests/run.sh` на локальном Supabase. Он применяет наборы `*_test.sql`; каждый SQL-сценарий откатывает данные итоговым исключением с отчётом. Ошибка `РЕЗУЛЬТАТ` ожидаема, строк `FAIL` быть не должно.

Имена, логины, суммы, идентификаторы и токены в тестовых данных вымышлены.
